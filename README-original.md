## GitHub Pages

Upload `index.html`, `styles.css`, `app.js`, and `assets/logo.png` into the repository root (or keep the folder structure exactly as provided), then enable:

Settings → Pages → Deploy from a branch → main → /root

## Editing

The `Edit` button allows local browser editing of speaker name/title/summary and image upload. Static websites cannot write changes back into GitHub without a backend or authenticated API, so local changes are stored in `localStorage`. Export JSON to back up the edits.
